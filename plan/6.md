# 6. Prefix Lists

| vtysh                 | gRPC              | Что делать          |
| --------------------- | ----------------- | ------------------- |
| `ip prefix-list ...`  | `EditCandidate()` | Создать prefix-list |
| `show ip prefix-list` | `Get()`           | Читать prefix-list  |





```sh
grpcurl -plaintext -import-path ./frrpb -proto frr-northbound.proto -d '{"type":"CONFIG","encoding":"JSON","path":["/frr-filter:lib"]}' localhost:50051 frr.Northbound/Get
```

```sh
grpcurl -plaintext -import-path ./frrpb -proto frr-northbound.proto -d '{}' localhost:50051 frr.Northbound/CreateCandidate
```
