# 7. Route Maps

| vtysh            | gRPC              | Что делать        |
| ---------------- | ----------------- | ----------------- |
| `route-map ...`  | `EditCandidate()` | Создать route-map |
| `match ...`      | `EditCandidate()` | Match rules       |
| `set ...`        | `EditCandidate()` | Policy actions    |
| `show route-map` | `Get()`           | Читать route-map  |

вот что надо дописать из комнда в configs/playground/workflow.yaml 


1.  Прочитать текущие route-map
2.  Создать candidate transaction
3.  Создать route-map TEST permit 10
4.  Commit route-map
5.  Создать candidate transaction
6.  Добавить match правило
7.  Commit route-map
8.  Создать candidate transaction
9.  Добавить set действие
10. Commit route-map
11. Проверить route-map
12. Создать candidate transaction
13. Добавить второй entry (например deny 20)
14. Commit route-map
15. Проверить route-map
16. Создать candidate transaction
17. Создать candidate для удаления entry
18. Commit route-map
19. Создать candidate transaction
20. Удалить entry
21. Commit route-map
22. Проверить удаление
23. Создать candidate transaction
24. Удалить route-map
25. Commit route-map
26. Проверить что route-map удалился
